ADI BRAND CONTEXT FOR GEN AI (Instagram / Social / Creative)
Version: 1.0
Project source reference: ADI website (Next.js / Tailwind / Framer Motion)
Goal: Give any GenAI enough visual + verbal context to produce assets aligned with ADI's web brand.

====================================================================
1) BRAND CORE (WHAT ADI IS)
====================================================================

Brand name:
- ADI
- Full name: Advanced Data Intelligence

What ADI does (core positioning):
- Consultora de data, automatizacion y analitica avanzada.
- Ayuda a empresas a mejorar eficiencia y rentabilidad mediante automatizacion, KPIs/dashboards, data science y productos digitales.

Core promise (do not overpromise / do not invent numbers):
- Ahorro de tiempo
- Reduccion de errores
- Trazabilidad
- Mejor toma de decisiones
- Crecimiento

Primary audience:
- Empresas con procesos manuales/repetitivos
- Operaciones con KPIs criticos (produccion, logistica, ventas, finanzas, RRHH, atencion al cliente)
- Equipos con datos en ERP/CRM/SQL/Excel/APIs pero sin uso real

Key pains to reference in content:
- Copiar/pegar
- Reportes manuales
- Errores recurrentes
- Falta de single source of truth
- Problemas detectados tarde

Brand personality:
- Premium tech
- Futurista, limpio, elegante
- Profesional y consultivo
- Pragmatico (no humo, no promesas vacias)
- Claro y orientado a negocio

Tone of voice:
- Directo, experto, aterrizado
- Explica impacto en operacion, no solo tecnologia
- Habla de sistemas, trazabilidad, decisiones, eficiencia
- Evitar hype vacio ("revolucionamos todo", "magia", etc.)

2) VISUAL DIRECTION (LOOK & FEEL)
====================================================================

General visual style:
- Dark premium base
- Glassmorphism moderado
- Detalles high-tech (lineas, halos, separadores con gradiente)
- UI limpia, sin saturacion
- Contraste alto y legible

Mood keywords:
- Deep navy
- Neon cyan controlled
- Glass panels
- Blueprint grid
- Data dashboard aesthetic
- High signal / low noise

What to avoid:

- Colores random / demasiados acentos
- Gradientes arcoiris
- Ilustraciones cartoon
- Sobrecarga de iconos/elementos
- Estetica startup generica morada

4) TYPOGRAPHY SYSTEM
====================================================================

Fonts (from next/font in app/layout.tsx):
- Body / UI / long text: Inter
- Headlines / brand display: Space Grotesk

How they are used:
- Headlines: Space Grotesk (font-display)
- Body copy: Inter (font-sans)
- Small labels/badges often use uppercase + tracking

Visual typography style:
- Headlines: bold, compact, clear, modern
- Body: clean and readable
- Labels: uppercase, tight but intentional spacing

Typical patterns from site:
- H1 hero: large, strong, not overly decorative
- Section titles: 3xl to 5xl range (responsive)
- Descriptions: muted text, smaller than headlines
- Labels/eyebrows: uppercase with tracking ~0.16em

Tone in typography:
- Technical but human
- Premium, not playful
- Confident without shouting

5) UI COMPONENT STYLE TOKENS (IMPORTANT FOR AI VISUALS)
====================================================================

Buttons (from components/ui/button.tsx):

Primary button (highlighted CTA)
- Shape: pill / rounded-full
- Border: primary/60
- Background: primary/90 (cyan)
- Text: primary-foreground (dark navy)
- Shadow: glow
- Hover: slight lift (-translate-y-0.5), full primary
- Typical labels:
  - Solicitar diagnostico
  - Agendar diagnostico (30 min)

Secondary button (non-highlighted CTA)
- Shape: pill / rounded-full
- Border: border/80
- Background: glass/40 + backdrop blur
- Text: fg
- Hover: border and text shift toward primary
- Typical labels:
  - Ver servicios
  - Mas info / Explorar / Ver metodologia

Ghost button (rare)
- Transparent, no border emphasis
- Text shifts to primary on hover

Cards (from components/ui/card.tsx)
- Rounded corners: rounded-2xl
- Border: border/70
- Background: glass/45
- Backdrop blur
- Soft shadow
- Hover: slight lift and border highlights toward primary

Badge / Eyebrow labels (from components/ui/badge.tsx)
- Pill shape
- Border: primary/40
- Background: primary/10
- Text: primary
- Uppercase, small text, tracking

Section heading pattern
- Eyebrow badge + bold display headline + muted description
- Layout is spacious and structured

Glass panels:
- Semi-transparent dark layers
- Thin borders
- Soft blur
- Low-opacity highlights, not glossy overload

Glow behavior:
- Cyan glow used for primary CTA and selected emphasis
- Controlled, not neon everywhere
- Typical shadow-glow value:
  0 0 40px hsla(196, 100%, 65%, 0.25)

Separators:
- Gradient lines (transparent -> primary -> transparent)
- Used to imply precision/high-tech feel

7) MOTION + INTERACTION STYLE (FOR ANIMATED POSTS / MOCKUPS)
====================================================================

General motion principles:
- Smooth, subtle, intentional
- No aggressive zooms / no "gaming UI" chaos
- Respect reduced motion

On-site motion patterns:
- Section reveal on scroll: fade + translateY up (~18px)
- Duration around 0.55s easeOut
- Hero entry ~0.75s easeOut
- Soft pulse/ring in hero ~3.2s loop
- Navbar auto-hide on scroll down, reappear on scroll up

Microinteractions:
- Hover lift on cards/buttons
- Border/label color shifts toward primary
- Animated underline on active nav item

For social motion (if using video/reels):
- Use slow pan/parallax on background grid
- Minimal glow pulse on CTA label
- Stagger bullets/cards by 80-120ms
- Keep loops calm and premium

9) BRAND COPY STYLE (FOR POSTS, CAROUSELS, CAPTIONS)
====================================================================

Core messaging style:
- "Problema -> sistema -> resultado"
- Emphasize operational impact over technical jargon
- Explain what changes in day-to-day operations

Preferred message structure:
1. Dolor concreto (ej: reportes manuales, errores, datos dispersos)
2. Enfoque ADI (automatizacion, KPIs, data model, alertas, etc.)
3. Resultado esperado (sin inventar metricas)
4. CTA suave (agenda diagnostico / dejanos tu contacto)

Examples of good phrasing:
- Convertimos procesos manuales en sistemas que trabajan solos.
- Ordenamos datos y KPIs para que la operacion decida con claridad.
- Pasamos de reportes tardios a visibilidad accionable.
- Menos retrabajo. Mas trazabilidad. Mejor decision.

What NOT to say:
- "Aumentamos 300% tus ventas" (unless real and validated)
- "IA magica"
- "La solucion definitiva para todo"
- Claims con numeros inventados

Pillar 5: Insight / opinion (founder POV)
- "Un dashboard sin definicion de KPI no resuelve..."
- "Automatizar sin trazabilidad solo mueve el problema..."

Pillar 6: CTA / conversion
- Agenda diagnostico
- Dejanos tu contacto y te buscamos
- Cuando conviene Fase 0

Recommended mix (monthly):
- 40% education (problemas + soluciones)
- 25% authority (metodologia / criterios / POV)
- 20% practical tips
- 15% conversion posts (CTA)

11) VISUAL RULES FOR INSTAGRAM POSTS (GEN AI BRIEF)
====================================================================

Preferred formats:
- Feed portrait: 1080 x 1350 (best for reach and readability)
- Square: 1080 x 1080 (for simpler announcements)
- Story: 1080 x 1920 (adapt from feed assets)

Layout rules:
- Keep a strong focal headline
- Max 1 main idea per slide/post
- Use glass cards for grouped information
- Use primary cyan only for emphasis, not full background floods
- Leave breathing room (premium look = space)

Text density recommendations:
- Cover slide: 5-12 words
- Content slides: 25-60 words max
- Avoid paragraph walls

Safe margins:
- 72-96px internal padding on 1080x1350 layouts
- Keep key text away from edges

Visual motifs to reuse:
- Soft cyan halo behind key card
- Thin cyan gradient separator line
- Grid / blueprint background at low opacity
- Rounded 2xl and 3xl cards
- Data UI snippets / charts / KPI tiles

Icon style:
- Outline icons (lucide-like)
- Clean and technical
- Consistent stroke weight

14) FAST CONTENT WORKFLOW (RECOMMENDED)
====================================================================

Option 1 (Very practical, fast):
- ChatGPT / Gemini: idea + script + caption
- Canva Pro or Figma: layout using this brand guide
- Export feed + story versions

Option 2 (More control / more premium):
- ChatGPT: copy + structure
- Figma: reusable templates (3-5 master templates)
- AI image tool only for background / abstract visuals
- Manual export and scheduling

Option 3 (Most consistent with your site):
- Ask Codex/AI to generate HTML/CSS social mockups using the same color tokens as the website
- Screenshot/export as image (1080x1350)
- Polish in Figma/Canva if needed

Practical recommendation for ADI:
- Build 4 post templates and reuse:
  1) Problem/Insight card
  2) Carousel cover
  3) Framework/Method post
  4) CTA / offer post (Diagnostico / Fase 0)
